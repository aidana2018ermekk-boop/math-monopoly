# Математикалық монополия — онлайн нұсқа

Бір сынып (28 студент) немесе бүкіл ағым (100+ студент) бір уақытта әр түрлі құрылғыдан (телефон, ноутбук, планшет) ойнай алатын нұсқа. Мұғалім панелінде әр студенттің ұпайы, шығарған есептері, жіберген қателері және рейтингі тікелей кесте түрінде жаңарып тұрады.

## Не бар

| Бөлік | Мекенжайы | Кімге |
| --- | --- | --- |
| Студент экраны | `http://СЕРВЕР:3000` | Студенттер — код пен аты-жөнін жазып қосылады |
| Мұғалім панелі | `http://СЕРВЕР:3000/teacher` | Мұғалім — құпия сөзбен кіреді |

- **Сервер:** Node.js, сыртқы кітапханасыз (`npm install` қажет емес).
- **Нақты уақыттағы байланыс:** Server-Sent Events (сервер → браузер) және HTTP POST (браузер → сервер). Барлық браузерде, телефонда да жұмыс істейді.
- **Ойын барысы** `data/session.json` файлына сақталады — сервер қайта қосылса да ойын жалғасады.
- **Дұрыс жауаптар тек серверде** сақталады, студент браузеріне жауаптан кейін ғана жіберіледі.

## Талап

[Node.js](https://nodejs.org) 18 немесе одан жаңа нұсқасы (LTS нұсқасын жүктеп орнатыңыз).

## 1-нұсқа. Сыныпта, бір Wi‑Fi желісінде (ең оңай)

1. Мұғалімнің ноутбугына Node.js орнатыңыз.
2. Осы папканы ашып, іске қосыңыз:
   - **Windows:** `start-windows.bat` файлын екі рет басыңыз;
   - **macOS / Linux:** терминалда `node server.js`.
3. Терезеде мынадай мәтін шығады:
   ```
   Студенттерге арналған сілтеме:
      http://localhost:3000
      http://192.168.1.25:3000
   Мұғалім панелі:  http://localhost:3000/teacher
   Мұғалімнің құпия сөзі:  m482913
   ```
4. Мұғалім браузерде `http://localhost:3000/teacher` ашып, құпия сөзді жазады → **«Жаңа сессия ашу»**.
5. Экранда 6 таңбалы **ойын коды**, сілтеме және QR-код шығады. Оны проекторға көрсетіңіз.
6. Студенттер **сол Wi‑Fi желісінде** телефонмен `http://192.168.1.25:3000` (терезедегі сандар) ашып, кодты және аты-жөнін жазады.
7. Барлығы қосылған соң **«Ойынды бастау»** басыңыз. Студенттер үстелдерге автоматты бөлінеді.

> Windows «Брандмауэр» терезесін шығарса, **«Рұқсат беру»** басыңыз, әйтпесе телефондар қосыла алмайды.
> Құпия сөзді өзіңіз қойғыңыз келсе: `ADMIN_PASSWORD=мениң_сөзім node server.js` (Windows: `set ADMIN_PASSWORD=...` содан кейін `node server.js`).

## 2-нұсқа. Интернет арқылы (студенттер әр түрлі жерде)

**А) Жылдам туннель (тіркелусіз):** сервер ноутбукта жұмыс істеп тұрғанда, екінші терминалда:
```
npx cloudflared tunnel --url http://localhost:3000
```
Шыққан `https://....trycloudflare.com` сілтемесін студенттерге беріңіз. Мұғалім панелі: сол сілтеме + `/teacher`.

**Ә) Тұрақты хостинг (мысалы, Render.com, тегін тариф):**
1. Осы папканы GitHub репозиторийіне жүктеңіз.
2. Render.com → **New → Web Service** → репозиторийді таңдаңыз.
3. *Start command:* `node server.js`. *Environment:* `ADMIN_PASSWORD` = өз құпия сөзіңіз.
4. Берілген `https://...onrender.com` сілтемесін студенттерге беріңіз.

> Тегін хостинг біраз уақыт қолданылмаса «ұйықтап» қалады және қайта жүктелгенде `data/` папкасы тазаруы мүмкін. Сабақ соңында нәтижелерді **CSV** етіп жүктеп алыңыз.

## Ойын қалай өтеді

- Студенттер 1–4 адамнан **үстелдерге** бөлінеді (мұғалім таңдайды). 28 студент, үстелде 4 адам → 7 үстел; 100 студент → 25 үстел. Әр үстел — жеке монополия ойыны.
- Әр студент өз құрылғысынан ойнайды: кезегі келгенде сүйекті лақтырады, есеп шығарады, мүлік сатып алады. Үстелдегі басқалар сұрақты көріп, ойша шығарып отырады.
- Ережелер бір файлдық нұсқадағыдай: 1000 тиыннан бастау, жеңіл/орташа/қиын сұрақтар, жалдау ақысы, сыйлық пен айыппұл карталары, Ойлану бөлмесі, банкрот.
- **Ойын тоқтап қалмауы үшін:** студент 45 секунд ішінде сүйекті лақтырмаса — автоматты лақтырылады; желіден шығып кетсе — 12 секундтан кейін. Сұрақтың уақыты біткенде жауап қате саналады.
- Кеш келген студент бос орны бар үстелге автоматты қосылады.
- Беттің жаңаруы немесе интернет үзілуі ойынды бұзбайды — студент қайта ашса, сол жерден жалғастырады.
- Ойын соңында әр студент өз үстеліндегі нәтижені және **жалпы рейтингтегі орнын** көреді.

## Мұғалім панелі

- Ойын коды, сілтеме, QR-код.
- Баптаулар: үстелдегі ойыншы саны, режим (раундтар / мақсатты сома / соңғы қалған), раунд саны, қиындық, сұраққа уақыт, сүйек саны.
- Тікелей көрсеткіштер: студент саны (желіде қаншасы), үстелдер, барлық жауап, дұрыс/қате саны, сыныптың орташа дәлдігі.
- **Рейтинг кестесі** (секунд сайын жаңарады): орын, аты-жөні, үстел, тиын, шығарған есеп, қате, дәлдік %, мүлік, тақтадағы орны, күйі (кезегі / жауап беруде / күтуде / банкрот / аяқтады). Кез келген баған бойынша сұрыптау және іздеу.
- Студентті басқанда — оның **барлық жауабы**: сұрақ, студенттің жауабы, дұрыс жауап, түсіндірме; «Тек қателер» сүзгісі; ойыннан шығару батырмасы.
- **Санаттар бойынша дәлдік** (7 санат) және **ең көп қате жіберілген есептер** — қай тақырыпты қайталау керегін көрсетеді.
- **CSV жүктеу** — нәтижелерді Excel-де ашуға болады.

## Сыйымдылық

100 студентпен жүктемелік тест өткізілді: 26 үстел, 0 қате, сервер жады шамамен 60 МБ. Кәдімгі ноутбук 100–300 студентке жеткілікті.

## Файлдар

```
server.js              — сервер және ойын логикасы
server/questions.js    — 89 сұрақ (жауаптарымен, тек серверде)
public/index.html      — студент экраны
public/teacher.html    — мұғалім панелі
public/shared.js       — тақта, санаттар, карталар (ортақ)
data/session.json      — ойын барысы (автоматты жасалады)
```

**Сұрақ қосу:** `server/questions.js` файлына жаңа жол қосыңыз:
- 4 нұсқалы: `{"id": 89, "c": "der", "d": 2, "q": "Сұрақ", "o": ["дұрыс", "қате", "қате", "қате"], "e": "Түсіндірме", "type": "mc"}`
- сандық жауап: `{"id": 90, "c": "lim", "d": 1, "q": "Сұрақ", "a": 7, "e": "Түсіндірме", "type": "in"}`

`c` — санат (`lim`, `der`, `int`, `defint`, `mat`, `lin`, `ode`), `d` — қиындық (1, 2, 3), `id` — қайталанбайтын сан. Нұсқалардың бірінші элементі әрқашан дұрыс жауап (экранда араластырылады).
